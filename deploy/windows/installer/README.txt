АП — УСТАНОВКА НА ПК С WINDOWS
==============================

В архиве уже всё есть: программа с настройками (камеры, Xiaomi, Google Диск, журнал,
пользователи), Python, библиотеки, модели распознавания, go2rtc, ffmpeg, rclone, nssm.
Интернет для установки не нужен.

ВНИМАНИЕ: в архиве пароли камер и доступ к Google Диску. Не пересылайте его,
после установки удалите архив с флешки.

УСТАНОВКА (10–15 минут)
1. Распакуйте архив целиком (правый клик -> «Извлечь все…»), например на рабочий стол.
2. В распакованной папке: правый клик по INSTALL.bat -> «Запуск от имени администратора»
   (или двойной клик — он сам попросит права администратора).
3. Ждите. Установщик идёт по 10 шагам и пишет, что делает. В конце откроется
   http://localhost:8000 — логин admin и ваш пароль.
4. Если установщик остановился с ОШИБКОЙ — исправьте причину и запустите INSTALL.bat
   ещё раз: сделанные шаги повторятся без вреда. Журнал: install-log.txt рядом с INSTALL.bat.

Программа ставится в C:\autoservice-cams и работает как служба Windows:
стартует сама при включении ПК, даже если в Windows никто не вошёл.

ОБНОВЛЕНИЕ
Запустите INSTALL.bat из нового архива. Программа обновится, а настройки, база,
доступ к Диску и записи на ПК останутся как были.

УДАЛЕНИЕ
UNINSTALL.bat (от имени администратора) — удаляет службу, правила брандмауэра и папку
C:\autoservice-cams вместе с базой и записями. Спросит подтверждение.
После пробной установки на домашнем ПК — обязательно удалите.

УДАЛЁННЫЙ ДОСТУП (Tailscale) — вручную, после установки
1. tailscale.com/download -> установить на ПК, войти в свой аккаунт.
2. Значок Tailscale в трее -> Settings -> включить «Run unattended».
3. login.tailscale.com -> Machines -> «…» у ПК -> «Disable key expiry».
4. На телефоне: приложение Tailscale, тот же аккаунт -> адрес ПК 100.x.y.z
   -> в браузере http://100.x.y.z:8000
Проверить Tailscale без АП можно тестовой страницей: папка tailscale-test, README.txt в ней.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
Логи: C:\autoservice-cams\logs\ (app.log, go2rtc.log, ffmpeg-*.log, service.err.log).
- «порт 8000 занят» — закройте окно с АП, запущенной вручную, или тест Tailscale.
- Камера «Офис» не показывает, в go2rtc.log «TLS handshake timeout» — выключите VPN.
- Камера не в сети — ping <адрес камеры из config.yaml>, проверьте питание камеры.
- Диск: «invalid_client» / «unauthorized_client» — см. гайд, раздел «Если что-то не работает».
- Не открывается с телефона — сеть Windows должна быть «Частная» (установщик ставит сам).
Управление службой (PowerShell от администратора, в C:\autoservice-cams):
  .\nssm.exe restart autoservice-cams     .\nssm.exe stop autoservice-cams
